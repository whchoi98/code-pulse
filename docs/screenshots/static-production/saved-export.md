## [Claude Code 2.1.293, Haiku 5.5 지원 추가와 세션 안정성 수정](<https://code-pulse.whchoi.net/?entry=claude-code-f0dfd4cdfef10f9572e0&lang=ko>)

- 제품: Claude Code (CLI)
- 공식 발표일: 2026-10-07
- 버전: 2.1.293
- 구분: 새 기능

### 짧은 요약

Claude Code 2.1.293에 Haiku 5.5 지원이 추가됐으며, 원문은 이를 Anthropic API의 기본 Haiku 모델로 안내합니다. subagentStatusLine에 agentType이 추가되었고 mods의 도구 등록에는 isDeferred 옵션이 들어갔습니다. 세션 복구, 원격 제어, 키 입력 처리 등의 문제도 함께 고쳤습니다.

### 왜 중요한가요?

Haiku 5.5 사용 여부는 작업에 설정된 모델 이름을 확인해야 합니다. 이 모델은 1M 컨텍스트를 지원하며, 100K 토큰을 넘는 프롬프트에는 더 높은 단가가 적용됩니다. 서브에이전트 상태 스크립트는 agentType으로 커스텀 타입을 구분할 수 있습니다. HTTP MCP 연결의 메모리 누수와 컨텍스트 압축 이후 작업 완료 판단 오류도 고쳤습니다.

### 주요 변경 요약

- **Anthropic API의 기본 Haiku 모델이 Haiku 5.5로 변경**: claude-haiku-5-5가 추가되어 Anthropic API의 기본 Haiku 모델이 되었습니다. 1M 컨텍스트를 지원하며, 입력과 출력 단가는 100만 토큰당 $0.10과 $0.50이고, 100K 토큰을 넘는 프롬프트는 $0.50과 $2.50이 적용됩니다.
- **서브에이전트 상태 스크립트에서 커스텀 타입 구분 가능**: subagentStatusLine 페이로드에 agentType이 추가되어, 스크립트가 커스텀 서브에이전트 타입을 구분할 수 있습니다.
- **HTTP MCP 연결의 메모리 누수 수정**: HTTP MCP 연결이 닫힐 때까지 보낸 요청을 모두 붙잡고 있던 메모리 누수가 고쳐졌습니다.

### 적용 전 확인

- Haiku 5.5 사용을 검토한다면 모델 식별자 claude-haiku-5-5와 100K 토큰 초과 프롬프트의 요금 조건을 확인하세요.
- 서브에이전트 상태 스크립트를 쓴다면 subagentStatusLine 페이로드의 agentType 값을 읽도록 수정할 수 있습니다.
- 컨텍스트 압축 이후 Claude가 끝난 작업을 되돌리거나 다시 수행하던 문제가 있었다면 이번 버전에서 같은 현상이 있는지 확인하세요.

### 전체 변경 사항

총 56개

1. Anthropic API에서 기본 Haiku 모델이 되는 Claude Haiku 5.5\(\`claude-haiku-5-5\`\)가 추가되었습니다. 컨텍스트 창은 1M이며, 요금은 백만 토큰당 입력 $0.10, 출력 $0.50입니다. 프롬프트가 100K를 넘으면 입력 $0.50, 출력 $2.50으로 올라갑니다.
2. \`subagentStatusLine\` 페이로드에 \`agentType\` 필드가 추가되어, 스크립트에서 사용자 정의 서브에이전트 유형을 구분할 수 있습니다.
3. mod용 \`$.tool.register\`에 \`isDeferred\` 옵션이 추가되었습니다. \`false\`로 설정하면 도구 검색 뒤에 숨기지 않고, 처음부터 해당 도구의 스키마를 프롬프트에 나열합니다.
4. 컨텍스트 압축 직전에 수행한 작업을 압축 뒤에 수행한 것으로 잘못 이해해, 이미 끝낸 작업을 되돌리거나 다시 실행하던 문제를 수정했습니다.
5. HTTP MCP 연결이 닫히기 전까지 보낸 요청을 모두 보관하던 메모리 누수를 수정했습니다.
6. Claude가 작업 중일 때 보낸 메시지가 \`←\`로 세션을 백그라운드로 옮기는 과정에서 사라지던 문제를 수정했습니다. 대기 중인 메시지를 옮길 수 없으면 세션을 이동하지 않고 그 이유를 알립니다.
7. \`/model\`에서 effort를 ←/→로 조절할 때 가장 높거나 가장 낮은 단계를 넘으면 반대편 끝으로 돌아가던 문제를 수정했습니다. 이 때문에 Low가 모델의 기본 effort로 실수로 저장될 수 있었습니다.
8. \`--chrome\`으로 시작한 세션에서 \`/tui\`를 실행하면 Claude in Chrome 연결이 끊기고 \`--no-chrome\`이 무시되던 문제를 수정했습니다.
9. 호스트, 권한 규칙 또는 \`--tools\` 목록이 \`SendMessage\`를 제거한 세션에서, 이 도구로 서브에이전트의 작업을 계속하거나 메시지를 보내라고 Claude에 안내하던 문제를 수정했습니다. 재개된 세션에도 적용됩니다.
10. 서브에이전트나 \`--agent\` 세션에서 자체 도구 목록에서만 빠진 기본 제공 도구를, 세션 전체에서 비활성화된 것으로 잘못 알려주던 문제를 수정했습니다.
11. claude.ai와 동기화된 스킬의 설명을 고쳐도 새 대화나 \`/clear\` 전까지 모델에 반영되지 않던 문제를 수정했습니다.
12. 로그인이 만료되었거나 곧 만료될 때 \`claude logs\`, \`stop\`, \`kill\`, \`rm\`과 \`claude daemon status\`, \`stop\`, \`uninstall\`을 실행하면 로그아웃되던 문제를 수정했습니다.
13. 세션 폴더를 일시적으로 읽지 못하면\(예: 열린 파일이 너무 많음\) 하단 표시줄의 에이전트 수가 사라지던 문제를 수정했습니다.
14. \`worker\`라는 이름의 사용자 정의 에이전트가 시작될 때 "Agent"로 표시되던 문제와, 에이전트가 끝난 뒤 상세 대화상자 제목에서 에이전트 유형이 빠지던 문제를 수정했습니다.
15. 게시 호출이 아직 스트리밍 중일 때 Artifact 도구의 기록 행이 잠시 \`Artifact\("\(unprintable path\)"\)\`로 표시되던 문제를 수정했습니다.
16. Linux에서 샌드박스 명령이 실행 중일 때 "could not be parsed" 설정 파일 문제를 이유로, 다른 체크아웃 안에 있는 저장소 등 일부 저장소의 \`/ultrareview\` 업로드가 잘못 거부되던 문제를 수정했습니다.
17. split-index 파일 때문에 \`/ultrareview\` 업로드가 거부될 때 안내하던 git 명령이 git이 인덱스를 읽지 못하게 만들 수 있던 문제를 수정했습니다.
18. 아주 긴 Remote Control 및 클라우드 세션에서 응답이 여전히 블록 단위로 나타나던 문제를 수정했습니다. 이제 응답이 스트리밍됩니다.
19. 자격 증명을 복구할 때마다 Remote Control이 세션 시작 기록을 다시 업로드하던 문제를 수정했습니다.
20. \`claude remote-control\`으로 시작한 세션에서 PushNotification이 "Remote Control inactive"라고 잘못 보고하던 문제를 수정했습니다.
21. 플러그인 hooks 작업자가 재시작되는 동안 mod의 \`classic.\*\` 이벤트 hooks가 건너뛰어져, 설정 hooks만 응답하던 문제를 수정했습니다.
22. \`$.session.append\`를 호출하는 mod에서 \`claude plugin test\`가 실패하던 문제를 수정했습니다. 이제 새로 추가된 \`mock.session\`으로 추가된 행을 다시 읽어 테스트할 수 있습니다.
23. Docker Desktop을 쓰는 Mac에서 \`~/.docker/bin\` 아래 링크 때문에 Bash 권한을 부여하는 \`claude plugin eval\` 실행이 모두 거부되던 문제를 수정했습니다. 이제 거부 안내에 자격 증명 저장소의 어느 부분에 링크가 있었는지 표시합니다.
24. \`desktop\` 정책이 \`builtinBrowserEnabled\` 같은 Claude Desktop 기본 제공 브라우저 키를 설정하면 Claude apps gateway가 시작되지 않던 문제를 수정했습니다.
25. \`claude agents\`가 권한 확인 우회를 제안해도, 동의가 \`.claude/settings.local.json\`이나 \`--settings\` 파일에만 저장돼 있으면 백그라운드 세션이 이를 무시하던 문제를 고쳤습니다. 이제 먼저 동의를 묻고, 우회를 무시하는 세션에는 짧은 안내를 계속 표시합니다.
26. 프롬프트에 보내지 않은 텍스트가 있거나 답변을 기다리는 질문이 있는데도 \`←\`를 누른 뒤 10초가 지나면 세션을 백그라운드로 보내던 문제를 고쳤습니다. 이런 경우에는 이동을 취소합니다.
27. 세션을 백그라운드로 옮기려고 \`←\`를 누른 직후, 권한 확인에서 Esc를 누르거나 피드백 없이 No를 선택해도 턴이 중단되지 않던 문제를 고쳤습니다.
28. 세션 폴더를 읽을 수 없을 때\(예: 열린 파일이 너무 많은 경우\) 에이전트 보기가 세션 목록을 잠시 자리 표시자 행으로 바꾸던 문제를 고쳤습니다.
29. Claude가 Read 도구 대신 Bash 도구에서 \`cat\`, \`head\`, \`tail\`, \`sed -n\`, \`grep\` 같은 단일 파일 명령으로 파일을 볼 때 경로 범위 규칙과 중첩된 CLAUDE.md 파일이 로드되지 않던 문제를 고쳤습니다.
30. 처음과 끝의 단어가 같은 붙여넣기 텍스트가 가끔 직접 입력한 내용처럼 Claude에 전송되던 문제를 고쳤습니다.
31. 붙여넣기 직후에 입력하거나 붙여넣은 액센트가 마지막 글자와 합쳐지면서, 붙여넣은 텍스트 속 스킬 이름이 직접 입력된 것으로 처리되던 문제를 고쳤습니다.
32. 보고서를 전송하는 중에 Ctrl+O나 Ctrl+Z를 누르면 \`/feedback\`이 초안 목록으로 돌아가, 전송을 취소할 수 없게 되던 문제를 고쳤습니다.
33. 파일이나 폴더를 삭제하지 못하면 \`claude purge\`가 종료 코드 0으로 조용히 끝나거나 터미널에서 응답 없이 멈추던 문제를 고쳤습니다. 이제 나머지 항목을 삭제하고 삭제하지 못한 항목을 나열한 뒤 종료 코드 1로 끝납니다.
34. keybindings.json 검사를 고쳤습니다. 단독 \`" "\`\(스페이스 키\)은 더 이상 오류로 보고되지 않으며, \`"ctrl+ k"\`처럼 키가 잘못된 경우에는 이제 경고가 표시됩니다.
35. vim 모드에서 공백만 있는 줄에 \`&gt;&gt;\`나 \`&lt;&lt;\`를 쓰면 커서가 줄 끝을 벗어나고, 이어서 \`x\`를 눌러도 아무것도 삭제되지 않던 문제를 고쳤습니다.
36. vim 모드의 Visual 모드에서 \`V\`를 누른 뒤 \`d\`로 줄 전체를 삭제하면 커서가 첫 번째 공백이 아닌 문자에 놓이도록 바꿨습니다. 이후 \`.\`은 커서가 있는 줄에 적용됩니다.
37. Windows에서 상태 표시줄, 훅 또는 셸 명령을 중지할 때 같은 프로세스 ID를 가진 관련 없는 프로세스가 함께 종료될 수 있던 문제를 고쳤습니다.
38. 2.1.281에서 바꾼 자동 모드 거부 메시지를 되돌렸습니다. 해당 변경은 거부가 정확한 명령뿐 아니라 결과 전체에 적용된다고 Claude에 알리는 내용이었습니다.
39. 2.1.290의 수정을 되돌렸습니다. 해당 수정은 컨테이너 재시작으로 대기 중인 \`/loop\` 깨우기나 예약 작업을 잃은 클라우드 세션이 잠든 상태로 남던 문제를 고친 것이었습니다. 이제 Claude에 이 사실을 알리지 않으며, 세션은 계속 잠든 상태로 남습니다.
40. Team 및 Enterprise 조직의 시작 절차를 개선했습니다. 정책과 관리형 설정을 더 일찍 가져오며, 응답이 멈춘 요청은 3초 뒤에 다시 시도합니다.
41. Claude in Chrome을 개선했습니다. 브라우저가 탭 목록을 늦게 보고할 때 거부되는 페이지 동작이 줄었습니다.
42. 클라우드 세션에서 브라우저에 연결할 수 없을 때 나타나는 Claude in Chrome 메시지를 개선했습니다. 여러 조직에 속해 있다면 확장 프로그램을 같은 조직에 로그인해야 한다고 안내하며, 이를 바꾸는 방법도 함께 알려줍니다.
43. Bash 편집 diff 안내를 개선했습니다. 나열된 파일이 명령 실행 중에 변경되었으며, 여기에는 다른 프로세스의 쓰기도 포함될 수 있다고 알립니다.
44. 아티팩트를 개선했습니다. Claude는 이제 2주 이상 된 라이브러리 버전을 정확한 버전으로 고정합니다.
45. 사용 중인 세션이 없을 때 claude.ai 스킬 동기화 변경 확인 주기를 10분마다에서 약 40분마다로 바꿨습니다.
46. 모델에 알리는 에이전트 목록과 MCP 서버의 정렬 순서를 바꿨습니다. 비ASCII 문자가 포함된 이름은 이제 ASCII 이름 뒤에 정렬됩니다.
47. OpenTelemetry \`claude\_code.at\_mention\` 로그를 바꿨습니다. 프롬프트를 읽을 때마다 에이전트 이벤트와 MCP 리소스 이벤트를 각각 최대 100개까지만 내보냅니다.
48. 셀프 호스팅 러너의 오케스트레이터가 폴링 사이에 고정된 5초 대신 4~6초를 기다리도록 바뀌었습니다. 같은 환경의 여러 레플리카가 한꺼번에 폴링하지 않도록 대기 시간을 분산합니다.
49. Claude Tag의 Claude in Slack이 Enterprise Grid의 워크스페이스 간 공유 채널에서 워크스페이스가 설정되지 않았다고 잘못 안내하던 문제를 수정했습니다. Slack이 메시지에 연결되지 않은 워크스페이스를 표시할 때 발생하던 문제입니다.
50. Claude Tag에서 관리자가 채널의 커넥터, 플러그인, 스킬 또는 규칙을 바꾸면 Claude in Slack이 작업 도중 멈추던 문제를 수정했습니다. 이제 변경 사항은 Claude가 작업을 마친 뒤에 적용됩니다.
51. Claude Tag의 Claude in Slack에게 스레드 루틴을 추가 메모와 함께 바로 실행하라고 요청하면, 결과를 해당 스레드에 게시하지 못하는 별도 실행이 시작되던 문제를 수정했습니다. 이제 실행을 그 스레드에서 이어갑니다.
52. Claude Tag 관리자 설정의 액세스 번들에 있는 Add a connector 대화상자가 Google 로그인을 한 번 하면 모든 Google 커넥터를 연결된 것으로 표시하던 문제가 수정되었습니다.
53. Claude Tag 관리자 설정은 아직 연결되지 않은 Enterprise Grid도 목록에 표시하며, 각 항목에 Connect 버튼이 함께 보입니다.
54. Claude Tag의 Claude in Slack은 관리자만 메시지를 게시할 수 있는 공지 채널에 참여할 때 소개 메시지를 게시하지 않습니다.
55. Claude Tag 관리자 설정의 채널 규칙 한도가 변경되었습니다. 워크스페이스별 페이지와 조직 전체 Slack 페이지 모두에서 한도가 20개에서 50개로 늘어났습니다.
56. Code Review의 Add a repository 대화상자가 이제 추가하지 못한 저장소를 각 사유와 함께 나열합니다. 예를 들어 GitHub 쓰기 권한이 없는 경우가 이에 해당합니다.
